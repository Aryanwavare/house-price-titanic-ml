Linear regression for house price prediction and logistic regression for Titanic survival prediction.

## Results
- **House price prediction:** Linear Regression, R² = 0.653 (see `house_predicted_vs_actual.png`)
- **Titanic survival:** Logistic Regression, accuracy = 80.45% on 179 test passengers

## Data
- House prices: [Kaggle House Prices dataset](https://www.kaggle.com/...) (save as `housing.csv`)
- Titanic: [Kaggle Titanic dataset](https://www.kaggle.com/c/titanic) (save as `titanic_train.csv`)

## Run
```bash
pip install -r requirements.txt
python assignment.py
```
